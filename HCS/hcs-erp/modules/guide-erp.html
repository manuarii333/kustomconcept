Navigation dans l'ERP
Comment se repérer et accéder rapidement aux pages
Comment accéder à une page
1
Sidebar gauche — cliquez sur le module voulu (icône + nom). Chaque module s'ouvre avec ses sous-onglets en haut de page.
2
URL directe — chaque vue a une URL permanente : index.html#module/vue — peut être mise en favori.
3
Topbar raccourcis — boutons rapides Devis, Factures et + pour créer un devis directement depuis n'importe où.
4
Outils HCS — applications standalone accessibles via le module Outils (icône 🔧) ou via URL directe modules/nom-outil.html.
💡 Astuce URL : Partagez une vue en copiant l'URL du navigateur. Ex : index.html#ventes/quotes ouvre directement la liste des devis.

Paramètres
Flux de vente standard HCS
1
Créer un devis — sélectionnez le client, ajoutez les lignes produits/prestations, définissez le règlement.
2
Confirmer — cliquez "Confirmer" ou enregistrez avec le statut Confirmé → une carte de planning est créée automatiquement dans Production.
3
Convertir en facture — quand la commande est prête, transformez en facture d'un clic.
4
Encaisser — dans la facture, enregistrez le(s) paiement(s). Le statut passe à "Payé partiel" puis "Payé". Les écritures comptables sont générées automatiquement et le Finance Dashboard est mis à jour.

Liens entre les modules
Comment les données circulent automatiquement dans l'ERP
Flux Devis → Planning → Facturation → Finance
1
Devis créé dans Ventes → Confirmé → carte de planning créée automatiquement dans Production/Planning
2
Devis → Facture : conversion en un clic, toutes les lignes et le client sont copiés
3
Facture payée → écritures comptables générées automatiquement (Banque ou Caisse) + transaction créée dans Finance Dashboard
4
MockupForge → Devis : les mockups créés pour un client apparaissent dans le sélecteur de devis pour les attacher directement
5
DTF Studio → Devis : le bouton "📎 Devis" dans DTF Studio attache l'export directement au devis ERP (même origine)
⚠️ Sync MySQL : Le bouton ☁↓ MySQL dans la topbar de l'ERP télécharge toutes les données du serveur dans votre navigateur. Utilisez-le à l'ouverture si vous êtes sur un nouvel appareil ou après une longue absence.
